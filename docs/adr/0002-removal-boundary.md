# worktree 삭제는 safe 판정인 것만, 강제 삭제 없이, 브랜치는 남긴 채 한다

worktree 화면은 손대지 않았고(추적되지 않은 파일까지 없음) 끝난 작업(`merged`이거나, `gone`이면서
앞선 커밋이 0임이 확인됨)인 것만 지운다. 손댄 것이 있으면 지우지 않고 이유를 보여 준다. 깨끗한
worktree를 지우면 체크아웃만 사라지고 브랜치와 커밋은 남으므로, 되돌리기 기록이 필요 없고 확인
물음도 `D`(safe 전부 삭제)에만 둔다.

로컬 브랜치는 지우지 않는다. squash 병합된 브랜치는 `git branch -d`가 거절하므로 지우려면 `-D`가
필요한데, 그 문을 열면 "잃을 것이 없는 것만 지운다"는 원칙이 무너진다. 브랜치 정리는 이 플러그인의
경계(원격을 알아야만 답할 수 있는 질문) 바깥이다. herdr-shear가 되돌리기 기록에 공을 들인 것은
강제 삭제를 지원하기 때문이며, 우리는 그 문을 열지 않는다.
